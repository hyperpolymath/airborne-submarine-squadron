== What this is, and how it works

*What it is.* A short, dated, signed record of what can honestly be claimed
about *Airborne Submarine Squadron* (ASS) at one exact commit. ASS is a
Sopwith-style arcade game in which an attack submarine also flies. It has a
plain-JavaScript engine (`gossamer/`), a small Bun game server (`run.js`,
`server/ass-server.js`), and an AffineScript core (`src/main.affine`) that is
meant to compile to an optional WASM co-processor. It is published as a static
site through GitHub Pages.

*How it stays trustworthy.*

. *Ground truth, not memory.* Every claim below comes from running the project's
  own checks in the session that wrote this file. Where a status document
  disagrees with a live run, the live run wins and the document is named as
  stale.
. *A frozen anchor.* The exact commit, time window, working-tree delta and
  toolchain are recorded in <<verifiable-anchor>>.
. *A real signature.* The file is landed by a signed git commit. That signature
  over this content, with the anchor as its parent, is the affirmation. The
  prose alone is not.

but its compiled WASM does not match the reference twin. Two of CI's own

[#nuance]
=== The honest nuance you must not lose

* *"The suite passes" depends on where and how you run it.* Here are the four
  runs from this session, each at the anchor SHA:
+
[cols="3,2,3",options="header"]
|===
| Command and tree | Result | Cause of each failure
| `bun test`, git worktree
| 282 pass, 3 skip, *3 fail*, rc=1, 50.42 s
| 2 timeouts at 5000 ms in `test/fixed_step_test.js`. 1 contract test
  (`.git exists — repo is standalone`), because a worktree's `.git` is a file.
| `bun test`, full clone
| 285 pass, 3 skip, 0 fail, rc=0, 21.85 s
| none
| `bun test --coverage` (exactly what CI runs), full clone
| 278 pass, 3 skip, *7 fail*, rc=1, 90.94 s
| all 7 were 5000 ms timeouts, in the frame-rate-independence, camera-lurch,
  redraw-independence and seeded-world tests
| `bun test --coverage --timeout 60000`, full clone
| 285 pass, 3 skip, 0 fail, rc=0, 30.20 s
| none
|===
+
`test/fixed_step_test.js` run alone in the worktree gave 22 pass, 0 fail in
8.51 s. Every failure seen was a timeout or the worktree `.git` assumption. No
assertion about game behaviour failed in any run. But CI's own `bun test
--coverage` step *did* fail on this machine. So these tests are sensitive to
load, and on a slow or busy runner they can fail without any code defect.
* *The two AffineScript type-check tests in `test/smoke_test.js` only check
  something when a compiler is present.* Without one they print `[skip]` and
  return, which counts as a pass. A compiler was present here
  (`/usr/local/bin/affinescript`), so they checked for real. `test.yml`
  installs no AffineScript compiler, so in CI those two tests pass without
  checking anything. This is an inference from reading `test.yml`. No CI log
  was read.
* *The 3 skips* are the `skipIf` tests that need a built WASM artifact, in
  `wasm_artifact_test.js`, `compatibility_test.js` and `smoke_test.js`. They
  skip because no conforming artifact exists (see <<fenced>>).
* *The benchmark figures are timings from one loaded machine.* They are not
  baselines. The baselines in `READINESS.adoc` were taken under Deno 2.7.7 on
  different hardware.

[#fenced]
=== Known-incomplete but honestly fenced

* *The WASM co-processor does not conform.* `./build.sh` compiled
  `src/main.affine` and verified the output with `sim/verify_artifact.js`.
  That verifier rejected it: `init_state differs from reference at tick
  (artifact 29, reference 0)`; all five scenarios differed at step 0; and
  `soak: trapped after 141 calls (Out of bounds memory access ...)`. The
  script then *deleted the artifact and exited 2*. The guard that makes this
  loud is `build.sh` together with `sim/verify_artifact.js`. The game runs
  without the co-processor, and README's *Status* says so. This session does
  not say whether the defect lies in `src/main.affine` or in the local
  compiler build (`fefac21`, uncommitted changes). Both are possible.
* *Three WASM-artifact tests are skipped, not passed.* `bun test` reports them
  as skips, so they cannot be mistaken for passes.
